# Arch-spec 0.1.1 — tiles de chão reais

## Decisão de load

**Falha cedo no `CityScene.load`** se tileset JSON ou PNG estiver ausente/inválido.  
Sem fallback silencioso para cores (as cores permanecem só no código como referência legada, não usadas se o tileset carregar).

## Formato dos assets

| Artefato | Path |
| -------- | ---- |
| Sheet | `public/assets/tiles/city-ground.png` |
| Meta | `public/assets/tiles/city.json` (`TilesetData`) |

Sheet: **1 linha × 5 tiles**, `tileSize` **32**, ordem = `TileId`:

| Index | name |
| ----- | ---- |
| 0 | `stone_a` |
| 1 | `stone_b` |
| 2 | `sidewalk` |
| 3 | `grass_a` |
| 4 | `grass_b` |

Geração: kind `path` (ou prompts dedicados) → revisão visual → pack/resize 32×32 com ImageMagick → promover.  
Intermediários ficam em `public/assets/generated/path/` (não editar à mão).

## APIs

```ts
// platform
function loadImage(url: string, signal?: AbortSignal): Promise<HTMLImageElement>
function loadJson<T>(url: string, signal?: AbortSignal): Promise<T>

// runtime ids (config)
ASSET_IDS.cityTileset      // 'tileset/city'
ASSET_IDS.cityTilesTexture // 'tex/city-tiles'
```

`RenderSystem` recebe `AssetStore` + `textureId` do tileset (ou lê de `ASSET_IDS`).

Src rect:

```
col = tileId % columns
row = floor(tileId / columns)
src = { x: col * tileSize, y: row * tileSize, w: tileSize, h: tileSize }
```
