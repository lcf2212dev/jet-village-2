# Arch-spec 0.1.2 — Guerreiro completo (8 dirs + run/sit)

## Decisões

| Tópico | Decisão |
| ------ | ------- |
| Load | **Falha cedo** no boot se atlas JSON ou PNG do guerreiro ausente/inválido |
| Sit | **Hold** `KeyC` → `intent.sit`; bloqueia movimento enquanto ativo |
| Run | **Hold** `ShiftLeft`/`ShiftRight` → `intent.run`; velocidade `RUN_SPEED` |
| Attack cancela sit | sim — `attack` tem prioridade sobre `sit` |
| Arte | Gerar por **estado** (kind `character`) com fundo transparente; empacotar em um sheet se necessário |
| Atlas | `startFrame` opcional em `AtlasAnimation` (strips horizontais por direção) |
| Fallback render | Placeholder geométrico só se clip resolvido não existir (load do asset ainda é obrigatório) |

## Prioridade de `AnimState`

1. `death`  
2. `attack` (one-shot)  
3. `sit`  
4. `run` se movendo + run  
5. `walk` se movendo  
6. `idle`

### Layout do atlas (meta)

- `frameSize` fixo (ex. 64×64 ou 96×96 — medido após pack).  
- Pivot nos pés (`pivot.y` ≈ frameH − 8).  
- Uma **row por direção** (ordem):  
  `down`, `down-left`, `left`, `up-left`, `up`, `up-right`, `right`, `down-right`  
- Em cada row, colunas por estado com `startFrame`:

| Bloco | startFrame (exemplo 4/6/6/4/4/6) | frames | loop |
| ----- | -------------------------------- | ------ | ---- |
| idle | 0 | 4 | true |
| walk | 4 | 6 | true |
| run | 10 | 6 | true |
| attack | 16 | 6 | false |
| sit | 22 | 4 | true |
| death | 26 | 6 | false |

Valores reais no JSON promovido podem divergir se a packagem ajustar; o runtime só lê o JSON.

### Geração

```
generate-asset kind=character
subject: medieval warrior with one-handed sword, cozy pixel art
extra: transparent background; 8 directions; animation = <state>; …
```

Reforçar **transparent background / alpha / no solid backdrop** em todo `extra`.

## APIs TS

```ts
// AnimState
type AnimState = 'idle' | 'walk' | 'run' | 'attack' | 'sit' | 'death';

// PlayerIntent
{ moveX; moveY; attackPressed; killPressed; runHeld; sitHeld }

// GameAction (+ Run, Sit)
// config
WALK_SPEED = 96
RUN_SPEED = 154  // ~1.6×
KEYMAP: Shift* → Run, KeyC → Sit

// AtlasAnimation
{ row, frames, fps, loop, startFrame?: number }

// frame column
col = (clip.startFrame ?? 0) + clamp(frame, 0, frames-1)
src = { x: col * fw, y: row * fh, w: fw, h: fh }
```
