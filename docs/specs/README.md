# Specs de versão — Jet Village 2

## Convenção

```
docs/specs/<MAJOR>.<MINOR>.<PATCH>/<MAJOR>.<MINOR>.<PATCH>.md       # produto
docs/specs/<MAJOR>.<MINOR>.<PATCH>/<MAJOR>.<MINOR>.<PATCH>-arch.md  # arch (após aceite)
```

## Fluxo

1. **Antes do código** — criar/atualizar a spec de produto e **aguardar aprovação**.
2. **Durante** — se o comportamento mudar, atualizar a spec no mesmo commit.
3. **Ao fechar** — consolidar o aceito em `docs/ESPECIFICACAO.md` (quando existir) e marcar status em `docs/PLANO.md`.
